DLNA / Orico NAS

สำคัญ: เว็บเบราว์เซอร์ไม่สามารถเปิดโฟลเดอร์ SMB เช่น \\NAS\หนัง โดยตรงได้ หน้านี้จึงใช้ DLNA/UPnP ContentDirectory ของ NAS เพื่อค้นหาไฟล์ VORTEX รุ่นนี้ใช้ TS200 DLNA Proxy เป็นตัวกลาง เพื่อหลีกเลี่ยง CORS และค้นหา ContentDirectory จริงของ TS200

ต้องเปิด vortex-ts200-proxy.js ก่อนใช้งาน; ถ้า VORTEX เปิดจากเครื่องเดียวกันใช้ค่านี้ได้เลย

เวอร์ชันนี้ไม่ต้องกรอก endpoint เอง — Proxy จะค้นหา ContentDirectory ของ TS200 ผ่าน SSDP อัตโนมัติ

โดยทั่วไป Root คือ 0; ถ้าต้องการสแกนโฟลเดอร์เฉพาะ ให้ใช้ Object ID ของโฟลเดอร์นั้น

TS200: รุ่นนี้ใช้ Weline OS และรองรับ DLNA/Samba โดย DLNA จะเผยแพร่เฉพาะโฟลเดอร์ที่เพิ่มไว้ใน LAN Share → DLNA ของ NAS ดังนั้นต้องเพิ่มโฟลเดอร์หนัง/ซีรีส์ใน DLNA Scan Path ก่อนสแกนจาก VORTEX
